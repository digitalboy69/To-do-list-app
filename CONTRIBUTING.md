# Contributing

1. Fork the repo and create a branch.
2. Open the project in Android Studio (Ladybug or newer, JDK 17) or run `gradle assembleDebug`.
3. Keep changes focused, and make sure the **Build APK** workflow passes on your pull request.
4. Describe what you changed and, for UI changes, add a screenshot.

Bug reports and ideas are welcome in the issue tracker.
